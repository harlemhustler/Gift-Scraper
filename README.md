# Gift Scraper Foundation Demo

This is the portfolio-safe, Spring-era foundation demo for the EcoPlug gift workflow. It is not a live fulfillment engine. It is a guided storefront walkthrough that shows the user journey through discovery, rewards, cart behavior, and the checkout UI experience.

## Current positioning
- Public GitHub repo: https://github.com/harlemhustler/Gift-Scraper
- Live storefront demo: https://thshvr-1p.myshopify.com/?pb=0
- Store password: choffa

The current demo is intentionally designed to guide users through the interface at checkout so they can see the UX flow, basket behavior, and the purchasing journey without implying that the system is currently operating as a live automated fulfillment stack.

## What this demo represents
- A storefront reward flow inspired by the old Spring theme and gift-match UI.
- A clear proof-of-concept for product discovery and ranking logic that could support seasonal offers and gifting.
- The documented foundation for the wider system: AliExpress scraping research, DSers planning, and AutoDS-style automation groundwork.

## What it is not
This is not a live gift-fulfillment app and it does not claim real supplier automation is running. It is a portfolio-friendly demonstration of the UX and product flow that guides users through the checkout experience.

## Quick start
Open the live storefront at https://thshvr-1p.myshopify.com/?pb=0 and enter the password `choffa` to walk through the demo flow.
